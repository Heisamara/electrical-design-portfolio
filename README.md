# Electrical Design Portfolio

A portfolio website presenting three connected conceptual electrical design studies:

- Commercial Office Electrical Design
- Electrical Load Calculation and Panel Scheduling
- AutoCAD-to-Revit Data Preparation

Includes an illustrative office lighting plan and an interactive preliminary load calculator with CSV export.

## Project status

These are conceptual studies, proposed workflows, and a browser-based demonstration. Completed CAD drawing packages, Python applications, and native Revit models are not claimed. All engineering calculations are preliminary and not for construction. Ontario Electrical Safety Code compliance is not claimed.

## View locally

Open `index.html` in a browser. No installation or build is required.

## Hosting

Hosted on GitHub Pages from the main branch root.
